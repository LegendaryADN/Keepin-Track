# 💰 Keepin-Track

Un control de gastos diario, simple, intuitivo y sin complicaciones.

---

###  Características Principales

- **Registro Ultrarrápido:** Agrega tus compras diarias con monto, categoría y descripción.
- **Resumen Automático:** Suma tus gastos organizados por día, semana y mes.
- **Historial por Fechas:** Revisa en qué se te fue el dinero en días pasados.
- **Soporte para Móviles:** Diseñada para instalarse como App en tu celular Android.

---

###  Tecnologías Utilizadas

- **Next.js / React:** Para la interfaz gráfica interactiva.
- **Tailwind CSS:** Para el diseño visual.
- **Supabase:** Base de datos donde se guardan tus registros.
- **Vercel:** Plataforma donde se hospeda la Web App.
